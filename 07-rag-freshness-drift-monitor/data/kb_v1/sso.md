# Single sign-on

## SAML SSO
SAML SSO is available on the Enterprise plan only. Configure it under Settings > Security > SSO.

## SCIM provisioning
SCIM user provisioning is not supported. Users must be invited manually or through SSO just-in-time provisioning.
