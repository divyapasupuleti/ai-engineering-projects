# Single sign-on

## SAML SSO
SAML SSO is available on the Enterprise plan only. Configure it under Settings > Security > SSO.

## SCIM provisioning
SCIM user provisioning is now supported on the Enterprise plan. Connect Okta or Azure AD under Settings > Security > SCIM.
