# Release Notes

## Version 2.3
Version 2.3 adds SAML single sign-on for Enterprise plans and a new audit log export. The refund window was extended from 14 days to 30 days in this release.

## Version 2.2
Version 2.2 introduced webhook retries and raised the API rate limit from 300 to 600 requests per minute.
