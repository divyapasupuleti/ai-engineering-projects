# Security Policy

## Data retention
Customer content is retained for 90 days after workspace deletion and then permanently erased. Audit logs are retained for one year.

## Multi-factor authentication
Multi-factor authentication is mandatory for Owners and Admins. Members can enable it from their profile using an authenticator app.

## Data residency
EU customers have their data stored in the Dublin region. Data is not transferred outside the EU without a signed data processing agreement.
